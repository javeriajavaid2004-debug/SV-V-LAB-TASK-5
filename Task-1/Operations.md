# Task 1: Identify Operations

| Op-ID | Operation                           | Purpose                                                            |
| ----- | ----------------------------------- | ------------------------------------------------------------------ |
| OP-01 | Perform Sensor Self-Check           | Check whether essential sensors are working correctly.             |
| OP-02 | Check Environmental-Control Devices | Check whether environmental-control devices are working correctly. |
| OP-03 | Register Artifact                   | Record the artifact identification information.                    |
| OP-04 | Load Environmental Profile          | Load the required environmental limits for the artifact.           |
| OP-05 | Check Chamber Door Status           | Determine whether the chamber door is open or closed.              |
| OP-06 | Monitor Temperature                 | Continuously monitor chamber temperature.                          |
| OP-07 | Monitor Humidity                    | Continuously monitor chamber humidity.                             |
| OP-08 | Monitor Light Exposure              | Monitor the light level affecting the artifact.                    |
| OP-09 | Monitor Vibration                   | Monitor vibration inside the chamber.                              |
| OP-10 | Monitor Artifact Condition          | Monitor the condition of the artifact.                             |
| OP-11 | Detect Temperature Violation        | Detect when temperature goes outside the permitted range.          |
| OP-12 | Correct Temperature                 | Restore temperature to the required range.                         |
| OP-13 | Verify Temperature Recovery         | Confirm that temperature has returned to the permitted range.      |
| OP-14 | Detect Humidity Violation           | Detect when humidity goes outside the permitted range.             |
| OP-15 | Correct Humidity                    | Restore humidity to the required range.                            |
| OP-16 | Verify Humidity Recovery            | Confirm that humidity has returned to the permitted range.         |
| OP-17 | Activate Protection Controls        | Protect the artifact when normal correction fails.                 |
| OP-18 | Generate Operator Alert             | Inform the museum operator about a critical condition.             |
| OP-19 | Detect Significant Vibration        | Detect vibration that may risk the artifact.                       |
| OP-20 | Suspend Conservation Activities     | Stop activities that may increase risk to the artifact.            |
| OP-21 | Verify Vibration Stabilization      | Confirm vibration remains below the allowed threshold.             |
| OP-22 | Verify Environmental Conditions     | Check whether environmental conditions are safe.                   |
| OP-23 | Verify Sensor Status                | Confirm that required sensors are working.                         |
| OP-24 | Switch to Emergency Power           | Switch to emergency power after main power failure.                |
| OP-25 | Record Power Failure                | Record the power failure incident.                                 |
| OP-26 | Perform Safe Shutdown               | Safely stop the system when power is unavailable.                  |
| OP-27 | Verify Safe Artifact Removal        | Confirm that the artifact can be safely removed.                   |
